# Setup

Shared files for my Mac & Linux systems. This was written on Mac, for Linux, need to replace some paths which are Mac specific

## Dependencies

### Core
- [mise](https://mise.jdx.dev/getting-started.html)
- [zimfw](https://github.com/zimfw/zimfw)

### Cargo
- [bat](https://github.com/sharkdp/bat)
- [eza](https://github.com/eza-community/eza)
- [fd](https://github.com/sharkdp/fd)
- [starship](https://starship.rs/installing/)
- [zoxide](https://github.com/ajeetdsouza/zoxide)

### Go modules
- [fzf](https://github.com/junegunn/fzf): `go install github.com/junegunn/fzf@master`
